- `.impeccable/review/source-results-desktop.png` → `docs/images/source-check-desktop.png`
- `.impeccable/review/source-results-mobile.png` → `docs/images/source-check-mobile.png`

The captures use a 1440px desktop viewport or a 390px mobile viewport and include
the full page. Source-check answers in these captures are synthetic UI fixtures.
